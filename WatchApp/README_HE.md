# WatchApp בעברית

מדריך שימוש קצר ומדויק לאפליקציית השעון בפרויקט Curiosity OLED Base.

## תכונות

- תצוגות שעון: Digital, Analog, Binary, Alarm face
- מעורר עם כיבוי אוטומטי וחזרה למצב/תצוגה הקודמים
- תפריט הגדרות (זמן, תאריך, מעורר, מצב תצוגה, פומודורו)
- טיימר פומודורו עם הפסקות קצרות/ארוכות, יעד מחזורים ומד התקדמות
- מסך דיבאג אופציונלי (קומפילציה)
- שמירת הגדרות בפלאש לשחזור אחרי ריסט/כיבוי

## שימוש

### קלט

- `S1`, `S2`
- פוטנציומטר
- חיישן תאוצה: Flip ו-Shake

### מצב שעון

- `S2` לחיצה קצרה: מעבר בין תצוגות שעון
- `S1` לחיצה ארוכה: כניסה לתפריט
- `S2` לחיצה ארוכה: כניסה לפומודורו
- בזמן צלצול מעורר: `S1` קצר, `S2` קצר, Flip או Shake מכבים את המעורר

### מצב תפריט

- פוטנציומטר: ניווט ברדיאלי או שינוי ערך במסכי עריכה
- `S2` קצר: כניסה לפריט מסומן, מעבר שדה, או אישור
- `S1` קצר: ביטול וחזרה לתפריט ראשי
- Flip או Shake: יציאה מהתפריט וחזרה לשעון

### מצב פומודורו

- `S2` קצר: Start או Pause
- `S1` קצר: Reset למחזור עבודה
- `S1` ארוך: מעבר לתפריט
- `S2` ארוך: יציאה למצב שעון

שדות עריכת פומודורו בתפריט:
- `W` = דקות עבודה
- `B` = דקות הפסקה קצרה
- `C` = מספר מחזורים לעצירה

הפסקה ארוכה מתוזמנת לפי `long_break_after_sessions`.

### מצב דיבאג (אופציונלי)

זמין רק אם `DEBUG_MODE` פעיל בקומפילציה.

- לחיצה ארוכה על שני הכפתורים: מעבר למסך דיבאג
- `S1` קצר: קידום התאריך ביום אחד (בדיקת גלישה)
- `S2` קצר: הגדרת מעורר לדקה הקרובה ויציאה
- מוצג גם אישור מעבר תאריך `DD/MM>DD/MM`

## התמדה (Persistence)

ההגדרות נשמרות בפלאש ומשוחזרות אחרי אתחול. צריבה מחדש עשויה למחוק אותן, בהתאם להגדרות הצריבה.

## הגדרות בנייה

- `default` עם `-O2`
- `debug` ללא אופטימיזציה (`-O0`)
