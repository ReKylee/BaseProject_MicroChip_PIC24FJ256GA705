# WatchApp בעברית

אפליקציית שעון לבורד PIC24FJ256GA705 Curiosity עם מסך OLED צבעוני 96x96.
תומכת במספר תצוגות שעון, מעורר, טיימר פומודורו ותפריט הגדרות רדיאלי.

## חומרה

| קלט           | רכיב                                |
|---------------|-------------------------------------|
| S1, S2        | כפתורי לחיצה על הבורד              |
| פוטנציומטר    | פוטנציומטר מובנה בבורד                      |
| חיישן תאוצה   | ADXL345 (זיהוי Flip ו-Shake)       |

לחיצות מסווגות כ**קצרות** (<2s) או **ארוכות** (>=2s החזקה).

## מצבים

לאפליקציה ארבעה מצבי תצוגה. כל מצב מנהל את הקלט והציור שלו בנפרד.

### מצב שעון

מצב ברירת המחדל. מציג את השעה על אחת משלוש תצוגות:

- **Digital** -- HH:MM גדול עם עקבות שניות בצורת קשת
- **Analog** -- מחוגי שעון מטבלת גיאומטריה מחושבת מראש (60 נקודות)
- **Binary** -- שעה מקודדת בבינארי

פקדים:

| קלט          | פעולה                     |
|--------------|---------------------------|
| S2 קצר       | מעבר לתצוגת שעון הבאה    |
| S1 ארוך      | כניסה לתפריט הגדרות      |
| S2 ארוך      | כניסה לפומודורו           |

כשהמעורר מצלצל, התצוגה עוברת לתצוגת מעורר ייעודית.
ניתן לכבות עם S1 קצר, S2 קצר, Flip או Shake.
השעון חוזר אוטומטית לתצוגה ולמצב הקודמים.

### מצב תפריט

תפריט רדיאלי עם ניווט בפוטנציומטר. פריטי התפריט מסודרים במעגל;
סיבוב הפוט מסמן את האפשרות הנבחרת.

| קלט          | פעולה                                        |
|--------------|----------------------------------------------|
| פוט          | ניווט בין אפשרויות / שינוי ערכים בעריכה     |
| S2 קצר       | בחירה, מעבר שדה, אישור                       |
| S1 קצר       | חזרה לתפריט ראשי / ביטול                     |
| Flip/Shake   | יציאה מהתפריט, חזרה לשעון                    |

הגדרות זמינות:

| פריט           | שדות                                  |
|----------------|---------------------------------------|
| הגדרת שעה      | שעה (0-23), דקה (0-59)               |
| הגדרת תאריך    | יום (1-31), חודש (1-12)              |
| הגדרת מעורר    | שעה (0-23), דקה (0-59)               |
| מעורר פעיל     | כיבוי / הפעלה / חוזר (מפעיל מחדש אחרי ביטול) |
| פורמט שעה      | 12H / 24H                            |
| מצב תצוגה      | Digital / Analog / Binary            |
| פומודורו       | דקות עבודה (W), דקות הפסקה (B), מחזורים (C) |

### מצב פומודורו

טיימר עבודה/הפסקה עם מעקב אחר מחזורים.

| קלט          | פעולה                      |
|--------------|----------------------------|
| S2 קצר       | התחלה או השהיה             |
| S1 קצר       | איפוס המחזור הנוכחי        |
| S1 ארוך      | כניסה לתפריט               |
| S2 ארוך      | יציאה למצב שעון            |

הטיימר עובר במחזור: **עבודה -> הפסקה קצרה -> עבודה -> ... -> הפסקה ארוכה**.
הפסקה ארוכה מופעלת כל N מחזורי עבודה (לפי `long_break_after_sessions`).
יעד המחזורים (C) קובע כמה מחזורי עבודה לבצע לפני עצירה.

התצוגה מראה ספירה לאחור MM:SS, תווית מצב
(WORK / BREAK / LONG), מד התקדמות ומחווני מחזורים.

### מצב דיבאג

זמין רק בקומפילציה עם `DEBUG_MODE` מוגדר.

| קלט                | פעולה                                     |
|---------------------|-------------------------------------------|
| S1 + S2 ארוך        | הפעלה/כיבוי מצב דיבאג                    |
| S1 קצר              | קידום התאריך ביום אחד (בדיקת גלישה)      |
| S2 קצר              | הגדרת מעורר לדקה הבאה, יציאה מדיבאג      |

## ארכיטקטורה

```
WatchApp/
  watch_main.c/h          נקודת כניסה ולולאה ראשית (10ms)
  app_init.c/h            אתחול חומרה (OLED, I2C, חיישן תאוצה, טיימרים)

  shared/                 טיפוסים, מצב, מתמטיקה, עיצוב, עזרי UI
    watch_types.h         Enums ומבנים (WatchFace_t, MenuState_t וכו')
    watch_state.h/c       WatchState_t גלובלי
    watch_settings_store  שמירה בפלאש (עם CRC)
    fast_math.h           חלוקה מהירה ללא פעולות div
    watch_format.h        עיצוב מספרים ותאריכים
    watch_ui_widgets      פרימיטיבי ציור משותפים
    ui_layout.h           עזרי מרכוז וגודל

  watchCore/              לוגיקת שעון ומעורר
  watchFaces/             מרנדרי תצוגה (digital, analog, binary, alarm)
  watchInput/             כפתורים, פוטנציומטר, אירועי חיישן תאוצה
  watchManagers/          תיאום (ניתוב קלט, תצוגה, עדכוני זמן)
  watchMenu/              מערכת תפריט רדיאלי (מצב, קלט, ציור, אייקונים)
  pomodoroTimer/          מכונת מצבים ו-UI של פומודורו
  watchDebug/             מסך דיבאג (אופציונלי בקומפילציה)
```

כל תצוגה ומצב מממשים זוג `Draw()` (ציור מלא) ו-`DrawUpdate()` (עדכון חלקי).
הלולאה הראשית קוראת לפונקציית העדכון המתאימה בכל tick,
עם ציור מלא בהחלפות מצב או שינויי דגלים.

## התמדה

ההגדרות נשמרות בפלאש בכתובת `0x2A000` ומשוחזרות בעליה.
הרשומה כוללת magic word, בית גרסה ו-CRC-16 (CCITT-FALSE) לאימות.
שדות נשמרים:

- שעה ותאריך
- פורמט שעה (12H/24H)
- תצוגת שעון פעילה
- שעת מעורר, מצב פעיל ודגל חזרה
- הגדרות פומודורו (משכי זמן ויעד מחזורים)

צריבה מחדש עשויה למחוק את הנתונים השמורים, בהתאם להגדרות הצורב.
